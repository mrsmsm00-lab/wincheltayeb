# ونش إنقاذ الطيب: wincheltayeb.com

موقع ونش إنقاذ في محافظة السويس. المشروع جزئين في ريبو واحد:

| المجلد | إيه هو | بيترفع فين |
|---|---|---|
| `wincheltayeb/web/` | الموقع (Next.js 16) | سيرفر Coolify على `wincheltayeb.com` |
| `wincheltayeb/admin/` | لوحة التحكم (PHP خام + SQLite) | cPanel على `admin.wincheltayeb.com` |

## إزاي الجزئين بيكلموا بعض

```
لوحة التحكم (cPanel)  ──api.php (JSON)──►  الموقع (Coolify)
        │                                        ▲
        └──── بعد كل حفظ: POST /api/revalidate ──┘
```

- الموقع بيقرا المحتوى من `admin.wincheltayeb.com/api.php` ويعمله كاش 10 دقايق.
- بعد أي حفظ في اللوحة، اللوحة بتبعت للموقع يحدّث نفسه فوراً، ومعاه الـ sitemap والـ llms.txt.
- لو اللوحة وقعت، الموقع بيكمل شغال بالمحتوى المدمج في `web/content/seed.json`.

## 1) الرفع على GitHub

الريبو: https://github.com/mrsmsm00-lab/wincheltayeb

المشروع كله جوه فولدر `wincheltayeb/` عشان يتفصل عن أي مشروع تاني. الملفات اللي لازم تفضل في جذر الريبو: `.cpanel.yml` و`.gitignore` و`.github/`.

```bash
cd wincheltayeb-repo        # الفولدر اللي فكيت فيه الضغط
git init
git add .
git commit -m "ونش إنقاذ الطيب: الإصدار الأول"
git branch -M main
git remote add origin https://github.com/mrsmsm00-lab/wincheltayeb.git
git push -u origin main
```

الملفات السرية (`admin/config.local.php` وقاعدة البيانات والمرفوعات) متضافة في `.gitignore` ومش هتترفع.

## 2) سر مشترك

اعمل نص عشوائي طويل، واستخدمه في المكانين (Coolify ولوحة التحكم):

```bash
openssl rand -hex 32
```

## 3) الموقع على Coolify

1. **New Resource → Public/Private Repository**، واختار الريبو.
2. **Build Pack:** `Dockerfile`، و**Base Directory:** `/wincheltayeb/web`.
3. **Port:** `3000`.
4. **Domains:** `https://wincheltayeb.com,https://www.wincheltayeb.com`.
5. **Environment Variables:**
   ```
   NEXT_PUBLIC_SITE_URL=https://wincheltayeb.com
   CMS_API_URL=https://admin.wincheltayeb.com/api.php
   REVALIDATE_SECRET=السر-اللي-عملته
   ```
   علّم على `NEXT_PUBLIC_SITE_URL` و`CMS_API_URL` إنهم **Build Variable** كمان.
6. فعّل **Auto Deploy**، فأي push على `main` هيتعمله deploy لوحده.

## 4) لوحة التحكم على cPanel

**المتطلبات:** PHP 8.1 أو أحدث، مع الإضافات `pdo_sqlite` و`mbstring` و`fileinfo` و`curl`. فعّلها من **Select PHP Version**.

1. اعمل الصب دومين `admin.wincheltayeb.com` وفعّل عليه SSL (AutoSSL).
2. **Git Version Control → Create**، وحط رابط الريبو.
3. افتح `.cpanel.yml` (في جذر الريبو) وغيّر `CPANELUSER` ومسار الصب دومين، واعمل push.
4. من Git Version Control دوس **Deploy HEAD Commit**.
5. من **File Manager** في مجلد الصب دومين، اعمل ملف `config.local.php`:
   ```php
   <?php
   return [
       'revalidate_secret' => 'السر-اللي-عملته',
   ];
   ```
6. افتح `https://admin.wincheltayeb.com/install.php`. اكتب السر كـ«كود التثبيت»، واعمل حساب المدير، والمحتوى كله هيتستورد.
7. امسح `install.php` ومجلد `install/` من السيرفر.
8. اتأكد إن `https://admin.wincheltayeb.com/api.php` بيرجع JSON، وإن `https://admin.wincheltayeb.com/data/site.sqlite` بيدي **403**.

> لو مش عايز تستخدم Git في cPanel، ارفع محتوى مجلد `wincheltayeb/admin/` بالـ File Manager أو FTP في مجلد الصب دومين، وكمّل من خطوة 5.

## 5) بعد الإطلاق

- **Google Business Profile:** اعمل بروفايل للنشاط في السويس بنفس الاسم والرقم. ده أهم حاجة للظهور في الخريطة.

- **الإحداثيات:** نقط المناطق تقريبية. راجعها من «المناطق»، واسحب العلامة للمكان الصح.

## مساعد الكتابة بالذكاء الاصطناعي (OpenAI)

في محرر أي صفحة في اللوحة فيه صندوق «مساعد الكتابة (AI)» بأربع أزرار: اكتب المقال كامل، حسّن وطوّل المحتوى، اعمل عنوان ووصف جوجل، اعمل أسئلة شائعة.

- **التشغيل:** اعمل مفتاح من platform.openai.com > API keys، وحطه من **الإعدادات > مساعد الكتابة**، أو في `config.local.php` بالمفتاح `openai_api_key`.
- **الأمان:** المفتاح بيفضل على السيرفر بس، ومش بيظهر في الـ API العام ولا في المتصفح.
- **الحد اليومي:** افتراضياً 40 طلب في اليوم، ويتغير من الإعدادات.
- **الموديل:** الافتراضي `gpt-4.1-mini`، ويتغير من الإعدادات لو OpenAI وقّفه أو عايز موديل تاني.
- **الحفظ:** النتيجة بتتحط في الخانات بس، ومش بتتحفظ غير لما تدوس «احفظ». وفيه زرار تراجع.
- **لو الكتابة بتفشل بعد حوالي دقيقة:** يبقى الاستضافة بتقطع الطلبات الطويلة. اطلب من الاستضافة يزوّدوا `max_execution_time`، أو استخدم «حسّن» على مسودة أقصر.

## الاستيراد الجماعي ودفعات المحتوى

- **ملفات الدفعات:** موجودة في `wincheltayeb/content-batches/`.
- **الاستيراد:** من اللوحة افتح **استيراد**، وارفع ملف الدفعة. الصفحات بتتضاف **كمسودة** عشان تراجعها، وبعدها تنشرها من القوايم بالتدريج.
- **التكرار:** إعادة استيراد نفس الملف مش بتكرر الصفحات.

## زرار «حدّث خريطة الموقع وبلّغ محركات البحث»

موجود في الصفحة الرئيسية للوحة، وبيعمل 3 حاجات:
1. يحدّث الموقع وخريطته.
2. يقرا كل الروابط منها.
3. يبعتها لـ IndexNow (Bing وYandex وغيرهم).

**مفتاح IndexNow:** بيتولد تلقائي من `REVALIDATE_SECRET`، وبيظهر على `/indexnow.txt`، فمفيش إعدادات زيادة.

**جوجل:** مش بيدعم التبليغ الفوري، فابعت `sitemap.xml` مرة واحدة في Search Console، واستخدم «Request indexing» للصفحات المهمة.

## المحرر الاحترافي

**الصيغ:** كل المقالات والصفحات والأقسام المخصصة بتتكتب Markdown (ويقبل HTML جواه)، أو **HTML كامل**. والتحويل بين الصيغتين بيحصل تلقائي.

**أدوات المحرر:**
- **أدوات التنسيق:** عناوين، وجداول، وقوايم، وروابط.
- **رابط داخلي:** بيختار من صفحات الموقع.
- **الصور:** رفع صور جوه المحتوى، أو بالسحب والإفلات.
- **إضافات جاهزة:** يوتيوب، وصندوق اتصال.
- **العرض:** معاينة جنب بعض، وملء الشاشة.
- **الحفظ:** حفظ تلقائي في المتصفح.
- **تنظيف اللصق:** بينضف الكلام الملزوق من Word وGoogle Docs.
- **مؤشرات سيو:** عدد H2، والروابط الداخلية، والصور اللي من غير وصف.

**الحماية:** الموقع بينضّف أي HTML قبل عرضه (sanitize-html)، فبيشيل السكريبتات والروابط الخطرة، والـ iframe بيتقبل من يوتيوب وفيميو وخرايط جوجل بس.

## الصفحة الرئيسية والقايمة

- **لوحة التحكم > الصفحة الرئيسية:**
  - ترتيب الأقسام بالسحب أو الأسهم.
  - إظهار وإخفاء أي قسم.
  - تعديل كل النصوص، وخلفية كل قسم.
  - إضافة أقسام مخصصة بالمحرر.
  - سيو الصفحة الرئيسية.
  - تقدر تكتب `{phone}` في أي نص، ويتحط مكانه الرقم.
- **لوحة التحكم > القايمة:** إضافة وحذف وتعديل وترتيب روابط القايمة، وإخفاؤها، وزرار مميز، وفتح في تبويب جديد.
- **القيم الافتراضية:** موجودة في `web/content/site-defaults.json` ونسخة منه في `admin/includes/site-defaults.json`، ولازم الاتنين يفضلوا شبه بعض.

## رفع جماعي للمعرض بوصف الذكاء الاصطناعي

من **صور وفيديوهات > رفع جماعي**: اسحب كذا صورة وفيديو مرة واحدة.

- **تصغير الصور:** الصور بتتصغّر في المتصفح لأقصى عرض 1920 بكسل، وده بيشيل كمان بيانات الموقع الجغرافي (EXIF) منها.
- **الرفع:** بيترفع ملفين مع بعض، ومعاهم شريط تقدم.
- **وصف الـ AI:** لو مساعد الـ AI مفعّل، كل صورة بتتبعت لـ OpenAI بجودة منخفضة (`detail: low`)، والـ AI بيكتب عنوان ووصف بالمصري.
  - **المنطقة:** لو اخترت منطقة، الـ AI بيذكرها في العنوان. ولو مختارتش، مش هيخترع مكان.
  - **تحذيرات:** بيحذرك لو في الصورة لوحة أرقام أو وش واضح، أو لو الصورة ملهاش علاقة بالشغل.
- **التعديل:** تقدر تعدّل العنوان والوصف بعد الرفع، أو من زرار «تعديل» تحت أي صورة في المعرض.
- **الاستخدام:** كل صورة بتتحسب طلب واحد من الحد اليومي للـ AI.

## الإحصائيات وGoogle Ads

نظام إحصائيات خاص بالموقع. كل البيانات على السيرفر بتاعك في `admin/data/stats.sqlite`، من غير Google Analytics ولا أي طرف تالت.

**إزاي بيشتغل:** الموقع بيبعت لـ `admin.wincheltayeb.com/hit.php` 3 حاجات:
- **الزيارات:** كل صفحة الزائر بيفتحها.
- **وقت البقاء:** كل 15 ثانية، والوقت ده بيتحسب بس والصفحة قدام الزائر.
- **الضغطات:** على الاتصال والواتساب والأزرار والقايمة والروابط.

**البوتات:** الزيارات اللي من بوتات أو أدوات فحص مش بتتحسب.

**من اللوحة > الإحصائيات** فيه التابات دي:
- **نظرة عامة:** الأرقام الأساسية في الفترة المختارة.
- **Google Ads:** تفاصيلها تحت.
- **المصادر:** الزوار جايين منين.
- **الدول والأجهزة.**
- **الصفحات:** وأنهي صفحة بتجيب مكالمات.
- **الضغطات.**
- **آخر الزيارات:** لكل زيارة صفحة بتوضح الزائر عمل إيه بالظبط وقعد قد إيه.
- **الزيارات المكررة:** حسب الـ IP.
- **إعدادات.**

**الفلاتر:** الفترة، والمصدر، والدولة، والجهاز، واللي اتصل، والزوار الراجعين، والـ IP. وتقدر تصدّر الزيارات Excel (CSV).

**Google Ads:**
- **التعرّف على الزيارة:** زيارة الإعلان بتتعرف من `gclid`، أو من `utm_source=google&utm_medium=cpc`.
- **التقارير:** حسب الحملة، والكلمة المفتاحية، وصفحة الهبوط، والجهاز.
- **ضغطات مشكوك فيها:** IP ضغط على الإعلان أكتر من مرة ومتواصلش.
- **الإعداد:** لاحقة الـ URL المطلوبة (Final URL suffix) مكتوبة جوه التاب.

**الدول:** في تاب إعدادات، دوس «حمّل قاعدة الدول». دي قاعدة DB-IP Lite، رخصتها CC BY 4.0، وبتتحدث كل شهر.

**استبعاد زياراتك:** ضيف الـ IP بتاعك، أو افتح `https://wincheltayeb.com/?wt_ignore=1` مرة من كل جهاز.

**الخصوصية:** الإحصائيات بتسجل IPs. البيانات بتتمسح لوحدها بعد مدة الاحتفاظ، والافتراضي 180 يوم. ويفضّل تذكر ده في صفحة خصوصية.

## صفحات الهبوط

**من اللوحة > صفحات الهبوط:**
- **القوالب:** 12 قالب جاهز بألوان وأشكال مختلفة: لافتة، وطوارئ، وليل، وتحذير، وواتساب أولاً، وبحر السخنة، ورملة الجلالة، ونقل تقيل، ووصول سريع، وبريميوم، وثقة، وأبيض وأسود.
- **الواجهة:** فيه 6 أشكال: sign وcenter وsplit وphoto وstripes وminimal.
- **مكان أزرار الاتصال والواتساب:** فيه 5 أماكن: شريط ثابت، أو أزرار عائمة، أو أزرار كبيرة في الواجهة، أو شريط فوق، أو زرار جانبي. وعلى الموبايل فيه دايماً شريط ثابت تحت.
- **الرابط:** إنت اللي بتختاره، زي `/ads` أو `/ads/sokhna`، ولحد مستويين.
- **العنوان الديناميكي:** `{keyword}` بيتبدل بالكلمة اللي جاية من الإعلان، من `keyword` أو `utm_term`، وبيتنضف من أي رموز. وفيه كمان `{area}` للمنطقة و`{phone}` للرقم.
- **قبل النشر:** الصفحة الجديدة بتبدأ مسودة، وليها رابط معاينة سري. وبعد النشر، مخفية عن جوجل (noindex) افتراضياً.
- **تحويلات Google Ads:** اختيارية. تحط Conversion ID وlabels، وكل ضغطة اتصال أو واتساب بتتسجل تحويل.

**التحقق من الروابط:** أي رابط بيتكتب لمقال أو صفحة أو صفحة هبوط بيتشيك فوراً لو مكرر أو محجوز لقسم في الموقع، وبيقترح بديل. والتشيك ده بيحصل تاني في السيرفر وقت الحفظ.

**إحصائيات صفحات الهبوط:**
- **الإحصائيات > صفحات الهبوط:** مقارنة بين الصفحات، وأنهي مكان زرار بيتضغط أكتر.
- **إحصائيات صفحة واحدة:** «إحصائياتها» بتفتح كل التقارير متفلترة على الصفحة دي بس.
- **فصل الإحصائيات:** تقارير الموقع الرئيسي بتبقى من غير صفحات الهبوط افتراضياً، وفيه فلتر «النطاق» لو عايز تغيّر ده.

**بنية المجلدات:** صفحات الموقع اتنقلت لـ `web/app/(site)/` عشان صفحات الهبوط تطلع من غير قايمة الموقع. والروابط على مستوى الدومين بيتعامل معاها `web/app/[...slug]/`، يعني صفحات الهبوط وأي «صفحة» جديدة من اللوحة.

### بناء صفحة الهبوط بالأقسام

كل صفحة هبوط بقت عبارة عن أقسام بترتّبها وتظهرها وتخفيها، وفيه 13 نوع:
- **الواجهة**
- **نقط الثقة**
- **الخدمات:** بصورة لكل خدمة.
- **أزرار اتصال:** بأي عدد، وفي أي مكان، وبـ 3 أشكال.
- **خطوات الطلب**
- **آراء العملاء:** بالنجوم.
- **صورة وكلام**
- **معرض صور:** برفع جماعي.
- **فيديو يوتيوب**
- **أرقام**
- **محتوى حر:** بالمحرر، Markdown أو HTML.
- **أسئلة شائعة**
- **الشريط الأخير**

**الصور:** جنب كل خانة صورة فيه زرار «ارفع صورة»: الشعار، وصورة الواجهة، وصور الأقسام، وصورة المشاركة.

**الشعار:** شعار الموقع وصورة المشاركة الافتراضية بيتحطوا من **الإعدادات > الشعار والصور**. وكل صفحة هبوط ممكن يبقى ليها شعار مختلف.

**ظهورها في جوجل:** صفحات الهبوط الجديدة بتبدأ **ظاهرة لجوجل**، وبتدخل في خريطة الموقع. وتقدر تخفيها من «اخفيها عن نتايج جوجل».

**الصفحات القديمة:** صفحات الهبوط اللي اتعملت قبل كده بتتحول لأقسام لوحدها أول ما تفتحها وتحفظها.

**تتبع الأزرار:** كل زرار ليه اسم في الإحصائيات بيوضح مكانه، زي «قسم أزرار 2» و«الزرار العائم» و«صورة وكلام». كده تعرف أنهي مكان بيجيب مكالمات أكتر.

### التحكم في تصميم صفحة الهبوط

في قسم **«التصميم»** في محرر كل صفحة هبوط فيه طريقتين:

**1. قالب بالأقسام:**
- **الواجهة:** شكلها مستقل عن القالب.
- **الهيدر:** عادي، أو شفاف فوق الواجهة، أو بلون القالب، أو غامق، أو مخفي.
- **الشعار:** مكانه يمين أو نص أو شمال الهيدر، أو جوه الواجهة، أو مخفي. وليه 4 أحجام، وتختار تظهر اسم الموقع جنبه ولا لأ.
- **الألوان:** 8 ألوان، كل واحد بيتغير لوحده، والخانة الفاضية بتاخد لون القالب.
- **شكل الأزرار والكروت:** دائري، أو ناعم، أو مربع.
- **صورة الواجهة:** مكانها جنب الكلام، أو خلفية بدرجة تغميق تختارها، أو فوق العنوان، أو مفيش. ورسمة الونش الافتراضية بتظهر أو تختفي.
- **CSS إضافي:** بيتطبق فوق التصميم.

**2. HTML مخصص بالكامل:**
- **الكود:** بتكتب HTML و`<style>` بنفسك، ومعاه معاينة مباشرة ونموذج تبدأ منه.
- **الأكواد الجاهزة:** `{phone}` و`{tel}` و`{whatsapp_link}` و`{call_button}` و`{wa_button}` و`{logo}` و`{keyword}` و`{area}`.
- **الأمان:** أي `<script>`، أو `on*` زي onclick، أو رابط `javascript:`، أو iframe من موقع غير يوتيوب وفيميو وخرايط جوجل، أو form، بيتشال تلقائي. والتنضيف في `web/components/landing/customHtml.js`.
- **التتبع:** روابط `tel:` و`wa.me` بتتسجل في الإحصائيات وتحويلات Google Ads لوحدها.

## عداد الزيارات والترتيب بيها

**في قوايم اللوحة:** في المناطق والمقالات والخدمات والصفحات وصفحات الهبوط، فيه عمود **«الزيارات»** لكل صفحة. العمود فيه 3 أرقام وشريط نسبة:
- المشاهدات.
- الزيارات المختلفة.
- ضغطات الاتصال والواتساب من جوه الصفحة.

**الترتيب:** تقدر ترتب حسب الأكثر زيارة، أو الأقل، أو الأكثر اتصال وواتساب، أو الأكثر دخول من برا الموقع، أو آخر تعديل.

**الفترة:** 7 أيام، أو 30، أو 90، أو سنة، أو من الأول.

**الصفحة الرئيسية للوحة:** فيها مربع «الأكثر زيارة في آخر 30 يوم» لكل نوع.

**الروابط العربي:** بتتعد صح، لأن الرابط المشفّر وغير المشفّر بيتحسبوا صفحة واحدة.
